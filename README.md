Actividad: Desafío de Calificaciones y Estadísticas 📊
Introducción 🧭
Este repositorio contiene el desarrollo del entrenamiento 2 del módulo 1, realizado por mi persona. En este proyecto se implementan diversas funcionalidades para manejar y analizar calificaciones de estudiantes mediante programación en Python.

Objetivos 🎯
1. Determinar el estado de aprobación
Solicitar al usuario ingresar una calificación numérica entre 0 y 100.

Evaluar si el estudiante aprobó o reprobó según la calificación ingresada.

2. Calcular el promedio
Permitir al usuario ingresar una lista de calificaciones separadas por comas.

Calcular y mostrar el promedio de las calificaciones ingresadas.

3. Contar calificaciones mayores
Preguntar al usuario por un valor específico.

Contar cuántas calificaciones en la lista son mayores que dicho valor.

4. Verificar y contar calificaciones específicas
Solicitar al usuario una calificación específica.

Verificar si esa calificación está presente en la lista y contar cuántas veces aparece, utilizando las instrucciones break y continue para controlar el flujo del programa.

Requisitos cumplidos ✅
Determinación del estado de aprobación:
El programa calcula el promedio de las notas ingresadas. Si el promedio es mayor o igual a 60, imprime un mensaje indicando que el estudiante aprobó; de lo contrario, indica que reprobó.

Cálculo del promedio:
Se utiliza la función sum() para sumar las calificaciones y len() para obtener la cantidad de notas, calculando así el promedio correctamente.

Conteo de calificaciones mayores:
El usuario ingresa un número y el programa cuenta cuántas calificaciones en la lista son mayores que ese número, mostrando el resultado.

Verificación y conteo de calificaciones específicas:
Se solicita una calificación al usuario y se recorre la lista para contar cuántas veces aparece esa calificación, empleando break para salir del ciclo si es necesario y continue para saltar iteraciones.
